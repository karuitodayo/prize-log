# PRIZE LOG

プライズゲーム（クレーンゲーム等）用のお小遣い・プレイ記録管理アプリです。

## 主な機能

- 月間予算の設定と残り予算の表示
- 「おでかけ」単位でのプレイ記録
- 今月の景品獲得数の集計
- 店舗ごとの訪問履歴・店内マップ（任意登録）

## 使用技術

- React + TypeScript
- Vite
- leaflet（地図表示）

## データの保存について

サーバーやデータベースは使用せず、ブラウザのlocalStorageにのみデータを保存します。

## セットアップ

```bash
npm install
npm run dev
```
